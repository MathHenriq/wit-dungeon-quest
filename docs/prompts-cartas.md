# Prompts das cartas — WIT Dungeon 2

Cada bloco é um prompt completo: copie e cole no GPT.

**Ordem recomendada:** gere o **Fogo** primeiro. Quando aprovar, gere os outros elementos **na mesma conversa** — o prompt já pede para manter o layout idêntico. Depois as full art e o verso.

**Por que sem texto e com janela magenta:** o nome, o custo e o efeito são escritos por código em cima da moldura (fica sempre nítido e editável), e a janela magenta é recortada automaticamente para encaixar a arte de cada carta.

```
Create an ORIGINAL trading card frame template for a fantasy card game called "WIT Dungeon". Use the layout logic of modern Pokémon TCG cards as a reference, but the design must be 100% original: no Pokémon logos, no Pokémon energy symbols, no existing brand elements.

If you already generated another WIT Dungeon frame in this conversation, keep EXACTLY the same layout, proportions and positions — change only the color theme, texture, trim and emblem described below.

FORMAT: vertical card, 1024x1536, rounded corners, thick outer border.

ELEMENT: FIRE
- Frame color and texture: volcanic orange-to-crimson gradient, subtle ember sparks and glowing lava-crack texture
- Trim and borders: warm polished gold
- Element emblem: a stylized flame, simple and original

LAYOUT (top to bottom). ALL TEXT AREAS MUST BE EMPTY — NO TEXT, NO NUMBERS, NO LETTERS, NO SYMBOLS WITH LETTERS anywhere on the card:
1. Header bar: a small empty pill badge on the left (card type), a long empty name area in the center, and on the right an empty circular cost gem next to a round medallion showing the element emblem.
2. Art window: a large rectangle taking about 45% of the card height, with a thin beveled metallic inner border. Fill the window with SOLID FLAT MAGENTA #FF00FF — a placeholder, no art, no gradient, no texture inside it.
3. A thin empty info strip right below the art window.
4. Effect text box: a large lightly tinted panel with a subtle parchment texture, completely empty.
5. Bottom bar: three small empty rounded slots side by side.
6. Footer: a small empty spot for a rarity symbol on the left and an empty area for a set number on the right.

STYLE: premium collectible card, clean, highly detailed, crisp edges, flat front-facing view, no perspective, no tilt, no shadow outside the card, plain neutral gray background around the card.
```
