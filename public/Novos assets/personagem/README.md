# Personagem (GPT)

Folhas geradas com os prompts de `docs/prompts-personagem.md`. Fundo magenta #FF00FF.

| Pasta | O que vai aqui | Arquivos |
|---|---|---|
| `corpos/` | Corpo base, 16 quadros (4 direções × 4 passos), um por tom de pele | `corpo-pele-1.png` … `corpo-pele-6.png` |
| `cabelos/` | 5 cabelos por imagem × 4 direções | `cabelos-1.png` … `cabelos-4.png` |
| `acessorios/` | 5 acessórios por imagem × 4 direções | `acessorios-1.png` … `acessorios-4.png` |
| `cima/` | 5 partes de cima por imagem × 4 direções | `cima-1.png` … `cima-4.png` |
| `baixo/` | 2 partes de baixo por imagem × 3 direções × 3 poses | `baixo-01.png` … `baixo-10.png` |
| `sapatos/` | 2 pares por imagem × 3 direções × 3 poses | `sapatos-01.png` … `sapatos-10.png` |
| `prontos/` | Personagens completos (moradores, desafiantes, visuais iniciais), 16 quadros | nome livre, ex.: `menino-cabelo-castanho.png` |

Toda imagem é revisada antes de entrar no jogo (público infantil, nada copiado de personagem existente).
