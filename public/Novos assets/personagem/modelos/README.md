# Modelos-base do personagem

Personagens inteiros, 16 quadros (4 direções × 4 passos), gerados com os prompts
`modelo-01` … `modelo-10` de `docs/prompts-personagem.md`.

Cores-molde (o jogo troca cada uma pela rampa que o aluno escolher):
cabelo ciano `#20B4C8`, parte de cima verde `#3CB44A`, parte de baixo azul
`#3456C8`, tênis branco, pele bege `#E8B48C`. Fundo magenta `#FF00FF`.
